:CUSTOM_ID: ot-001-1-result

- Category :: Bounded one-off verification.
- Criterion :: [[file:spec.org::#ac-001-10][AC001.10 - Portable build and verification]].
- Definition :: [[file:spec.org::#ot-001-1][OT001.1 - Build and tooling contract]].
- Result :: PASS.
- Procedure and expected result :: One local build/lint/test/vulnerability-check and Linux cross-compilation review, including govulncheck failure propagation and non-mutating locks. Installation twice to an OS temporary PREFIX preserved an unrelated sentinel and installed help/version. Isolated =make lint BIOME=missing-biome-tool= and =make lint TIDY=missing-tidy-tool= each failed at the intended missing-tool boundary.
